# ADR-002: Модель хранения данных

## Статус
Принято

## Контекст
Платформа обрабатывает сырые свечи, feature-датасеты, метаданные, результаты бэктестов и семантический слой. Требуется чёткое разделение источников истины.

## Решение
Строгое разделение по слоям:

| Тип данных | Хранилище | Формат |
|------------|-----------|--------|
| Raw candles | S3/MinIO | Parquet (fixed-point) |
| Feature datasets | S3/MinIO | Parquet |
| Инструменты, стратегии, эксперименты, orchestration | PostgreSQL | Реляционные таблицы |
| Результаты бэктестов, витрины | ClickHouse | Колоночные таблицы |
| Embeddings, семантика | Qdrant | Векторная БД |

## Правила
- Истина по сырым данным — Parquet в object storage
- Истина по моделям и метаданным — PostgreSQL
- Истина по результатам — ClickHouse
- Истина по семантике — Qdrant
- Ни один сервис не пишет напрямую в чужую БД
